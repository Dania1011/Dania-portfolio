# Dania Boban — Portfolio Website

A responsive, single-page personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, responsive layouts and animations
- `script.js` — mobile navigation, theme toggle, reveal effects and scroll progress
- `assets/Dania_Boban_Resume.pdf` — résumé linked from the homepage

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `dania-portfolio`).
2. Upload the three website files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will provide the published website URL.

## Before publishing — personalisation checklist
- Replace the generic GitHub project links with the exact repository URLs for each featured project.
- Review the included résumé PDF and replace it whenever you update your résumé.
- Review the wording of every experience and project description.
- Add project screenshots only if they do not reveal confidential company information.
- Check the website on mobile and desktop after deployment.
